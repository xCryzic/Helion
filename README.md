# HELION 2027

HELION is a React + TypeScript + Vite single-page site with a lightweight Node backend, native SQLite persistence, and a protected administration dashboard.

## Requirements

- Node.js 24 or newer (the backend uses the built-in `node:sqlite` module)
- npm

## Local development

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env`.
3. Generate an admin password hash with `npm run admin:hash` and place the printed value in `ADMIN_PASSWORD_HASH`.
4. Set `SECRET_KEY` to a long random value.
5. Run frontend and backend together with `npm run dev`.

The Vite site runs at `http://127.0.0.1:5173` and proxies `/api` to the backend at `http://127.0.0.1:8787`. Run `admin()` in the browser console or open `/admin` directly.

The SQLite database is created automatically at `data/helion.sqlite` unless `DATABASE_PATH` overrides it. Runtime database files and secrets are ignored by Git.

## Production

Run:

```text
npm run build
npm start
```

The production Node process serves both the built frontend and the API from one origin. Set `NODE_ENV=production` so session cookies receive the `Secure` flag, and terminate TLS at the application host or a trusted reverse proxy. If a proxy supplies client IP information, set `TRUST_PROXY=true` only when that proxy is controlled and replaces incoming forwarding headers.

Production hosting must provide a persistent writable filesystem for the configured SQLite path. Back up the database and its WAL state using a SQLite-aware backup process. Serverless hosts with ephemeral filesystems are not suitable without changing the persistence layer.

## Environment variables

- `ADMIN_PASSWORD_HASH`: scrypt password hash generated by `npm run admin:hash`.
- `SECRET_KEY`: long random secret used to sign opaque admin session cookies.
- `PORT`: backend port; defaults to `8787`.
- `HOST`: backend bind address; defaults to `127.0.0.1`. Container deployments commonly use `0.0.0.0`.
- `DATABASE_PATH`: SQLite file path; defaults to `./data/helion.sqlite`.
- `SESSION_HOURS`: admin session lifetime; defaults to `8`.
- `TRUST_PROXY`: whether to trust the first `X-Forwarded-For` value; defaults to `false`.

## Data and export behavior

Public clients can only submit to `POST /api/interest`. Participant reads and CSV export require a valid server-side admin session. The dashboard CSV export respects the currently active search, event, school, grade, and sort filters.
